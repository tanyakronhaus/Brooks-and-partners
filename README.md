# BROOKS & PARTNERS

Corporate website for **BROOKS & PARTNERS**, built as a responsive Hebrew RTL site with React, Vite, and CSS.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The build output is generated in `dist/public`.

## Deploying with Vercel

1. In Vercel, select **Add New → Project**.
2. Import the GitHub repository `tanyakronhaus/Brooks-and-partners`.
3. Leave the detected defaults unchanged. The included `vercel.json` sets the required build command and output directory.
4. Click **Deploy**.

All images and supplied Open Sans Condensed font files are committed to `client/public/assets`, so the site does not depend on temporary development-storage URLs.
